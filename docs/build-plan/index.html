Locked decisions

ProductAn open-source team layer under every coding agent. Core: the agent ledger, the review list and the team config. Runtimes, the gateway, bench and routing are plugins. No agent, no agent UI, no orchestrator, no compute.
StackTypeScript throughout. pnpm and turbo monorepo. CLI ships as one binary via bun build --compile. Postgres for the ledger, ClickHouse optional later. React, Vite and Tailwind for the console. Bifrost (Go binary, Apache) bundled as the gateway.
LicenseApache-2.0 core plus a commercial ee/ folder. Bundle only MIT, Apache, BSD, MPL or PostgreSQL-licensed code; check every upstream before bundling.
Logins and dataEach person signs in to their own vendor CLI. Never route other people's requests through one login. Hosted stores events and settings only, never subscription logins or provider keys.
OrderM0 foundations, then M1 to M11. Public launch at the end of M3. Contracts (M0.2) are signed off before parallel work starts.
Definition of doneEvery acceptance criterion checked; tests in CI; CLI help or docs updated; pull request reviewed and merged by Ronak, with a one-line reason for the decision.
Working rulesOne issue, one branch, one pull request. Main changes only through pull requests with green CI. No secrets in the repo. Vendor CLI versions recorded in fixtures.
SizesDev-weeks are size estimates for ordering work. Real pace is measured weekly and the plan is re-cut from that.

F01Ledger: one event schema across agentsSoloMust · 2 wk #4

One event schema across vendors: who, agent, model, tool call, target, decision, cost, time, session.

Acceptance criteria

  • A versioned event schema (JSON Schema plus generated TypeScript types) defines one record with who, agent, model, tool call, target, decision, cost, time and session, and every ingest path validates against it.
  • An event that fails validation is rejected with an error naming the field, and nothing is written.
  • Fixture events from hooks, OpenTelemetry, a gateway log and a vendor audit or compliance export each map to the schema, with a contract test per source.
  • Every event records its source, so a Bedrock, Console-key or cloud session that the Anthropic Compliance API skips still shows up from hooks or the gateway, labelled with where it came from.

  • Events can be queried by person, agent, model, session and time range through the API the console reads.

Contract and unit tests in CI with fixture events per source, plus a Postgres integration test for the append-only rule.
